# Sher Khan World — Bismillah First

The Android launcher now shows the Bismillah screen first on every app launch. The user taps **بِسْمِ اللّٰهِ سے شروع کریں** and then the existing Sher Khan World app opens.

The existing app page contains mobile/OTP, Gmail/Google and Facebook account options. This change only controls the opening screen; it does not claim that Google/Facebook OAuth or SMS OTP is live without provider credentials.
